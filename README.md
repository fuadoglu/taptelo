# Taptelo

Mobile-first public discovery for Telegram channels, groups and bots. Production domain: **taptelo.com**.

This repository currently contains the implementation specification. Start with [AGENTS.md](AGENTS.md) and the [delivery plan](docs/06-delivery.md). Work package T01 is ready to begin. Its acceptance commands and outputs are in [foundation acceptance](docs/07-foundation-acceptance.md). The deployment and provider launch gates are listed in [operations](docs/05-operations.md).
